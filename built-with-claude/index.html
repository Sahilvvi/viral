Built with Claude.

Claude is part of how a small studio ships cinema-level launch content at the speed the internet moves. This page is an honest account of where we use it today and where it goes next.

Where Claude helps us

● in use today   ○ planned

In use today

Building this website

The 3D scroll experience, interactive sections and this multi-page site were written and iterated with Claude Code. One person ships what used to take a front-end team.

In use today

Motion and reel pipeline

Our launch reels are authored as code (HTML, GSAP, Three.js) and rendered to video. Claude Code writes and debugs these compositions, so changing a model or a caption is an edit, not a rebuild.

In use today

Scripts, hooks and copy

Claude drafts hook alternates, scene-by-scene scripts with time-codes and platform captions, which our directors then shape into the final voice.

Planned

Vex, our launch assistant

The “Ask Vex” widget on our homepage answers from a short scripted FAQ today. We plan to power it with the Claude API so prospects get real answers about formats, timelines and scope, grounded in our own pricing and process docs.

Planned

Brief-to-plan intake

When a client submits a brief in the portal, Claude would read it and draft a first launch plan (hook ideas, format map, shot list) for a producer to review before the discovery call.

Planned

Review-room summaries

Condense frame-accurate feedback from a review room into a clean list of revisions per cut, so rounds of changes stay short and unambiguous.

What it looks like in practice

A reel is a composition written as code. This is the shape of the work Claude Code does for us when a client wants a change like “make the hook land half a second sooner.”

// launch-reel / scene 02 — reveal
const tl = gsap.timeline({ paused: true });
tl.from("#product", { scale: 0.6, opacity: 0, duration: 0.5, ease: "expo.out" }, 0.0)   // was 0.5s: hook lands sooner
  .from(".caption", { yPercent: 40, opacity: 0, stagger: 0.08 }, 0.2);

How we’ll use it responsibly

Do you pass client work through Claude?

Client briefs and unreleased products are confidential. Any Claude API use on client material will follow the data terms agreed with the client and Anthropic’s usage policies, and we’ll say so in the project scope.

Is the final film written by AI?

No. Claude helps with drafts and code. A director decides what ships, and every shot is human-directed.

Will you tell clients where AI is used?

Yes. Every package lists where generative tools are used, and clients can ask for a plain-language breakdown of the pipeline for their project.
